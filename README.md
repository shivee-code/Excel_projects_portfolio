# Project Details

## Project 01 — FNP Sales Analysis - Excel Dashboard

📁 Folder: `Project_01_FNP_Sales_Analysis/`

**Business Problem:** Analyze sales performance, customer purchasing behavior, and operational efficiency for Ferns N Petals (FNP) to support better business decision-making.

**Approach:** Developed an interactive Excel dashboard using Power Query, Pivot Tables, KPI reporting, and visualization techniques to monitor revenue trends and customer insights.

### Key Analysis & Insights

- Revenue trends across time and occasions
- Occasion-wise and category-wise sales performance
- Identification of top-selling products
- Customer order behavior analysis
- Delivery time and fulfillment performance insights
- Interactive dashboard for quick business decision-making

### Key Skills

Excel · Power Query · Pivot Tables · Charts · KPIs · Slicers · Timelines

🔗 Repository Link:  
Project_01_FNP_Sales_Analysis/

## Project 02 — Swiggy Sales & Customer Behavior Analysis - Excel Dashboard

📁 Folder: `Project_02_Swiggy_Sales_Analysis`

**Business Problem:** Analyze food delivery sales, customer behavior, ratings, and regional performance to identify operational and business growth opportunities.

**Approach:** Built an end-to-end Excel dashboard solution using Power Query, Pivot Tables, KPI reporting, and interactive visualizations for sales and customer analytics.

### Key Analysis & Insights

- Total Sales, Total Orders, Average Order Value (AOV), and Ratings KPIs
- Monthly, weekly, daily, and quarterly sales trend analysis
- Veg vs Non-Veg food revenue contribution
- Top-performing cities and state-wise sales analysis
- Customer satisfaction analysis using ratings data

### Key Skills

Microsoft Excel · Power Query · Pivot Tables · Pivot Charts · Map Charts · KPIs · Slicers

🔗 Repository Link:  
Project_02_Swiggy_Sales_Analysis
